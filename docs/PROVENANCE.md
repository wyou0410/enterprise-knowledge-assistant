# Project provenance

This project began with a document-grounded onboarding/process question-answering scenario and evolved into a standalone terminal application. The maintainer defined scope, selected the minimal CLI workflow and evaluation boundaries, and configured the services used for local live testing.

Development used AI assistance for implementation, tests, documentation and operational verification. The repository does not imply that every line was independently handwritten. No user study, organizational deployment, measured business-efficiency benefit or manually validated answer accuracy is claimed.

The public release has a fresh, curated history. Earlier account-specific deployments, operational notes, intermediary runs, private data and local machine identifiers are retained outside this repository. Aggregate live measurements are distinguished from reproducible synthetic tests; their limitations are documented in EVALUATION.md.
